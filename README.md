# seven_wonders
"7 Wonders of India" is an interactive web application that brings India's seven most iconic heritage monuments — the Taj Mahal, Hampi, Khajuraho Temples, Konark Sun Temple, Ajanta Caves, Qutb Minar, and Nalanda University — to life through a rich digital experience. Built using HTML5, CSS3, and Vanilla JavaScript, the application features.
